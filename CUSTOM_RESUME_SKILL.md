# Custom Resumes

Build a resume tailored to the job posting, using only facts about me from this file and from any resume I provide. If I have an existing resume, use it as the starting point. If I don't, build it from the "Facts about me" section. Highlight the skills the employer values, keep it to **one page**, and never invent experience.

## Before editing

1. Get the job posting (I will paste it, or search for it if I give a link or company name).
2. List 8-12 keywords and requirements that applicant tracking software would look for (tools, methods, domain words).
3. Rank them by **true priority**, not by the order listed. Check "required" vs "preferred", what appears under day-to-day responsibilities, and whether the same role at the same company repeats certain skills. If the research is thin, say so and fall back on the posting's emphasis.
4. Find my starting point:
   - If I have one or more existing resumes in this folder, use the closest one. If there are several, pick the best fit for the posting (or ask me).
   - If I have none, build the resume from "Facts about me" below. Ask me which format I want (Word, Google Docs, Markdown, LaTeX, etc.) if I haven't said.
   - Either way, save the result as a **new file**. Never overwrite my original resume.

## Folder and file naming

- New folder per application: `custom_[role]_[company]/` (lowercase, no spaces). Example: `custom_marketing_nike`.
- Resume file name: `[Firstname_Lastname_Resume].[docx/tex/md]`.
- If I have an existing resume, keep its template, fonts, margins, and section order. If not, use a simple, ATS-friendly layout: [e.g., Education, Experience, Projects, Skills].
- The resume **must stay on one page**. If it goes over, cut or compress content (drop the weakest bullet or project first). Do not shrink margins or fonts.

## How to tailor

Rewrite, don't just sprinkle keywords. Every change must stay true.

- **Experience:** Keep the same employers, titles, and dates. Reorder and rephrase bullets so the strongest matches to the posting come first. Format: action verb + what I did + result. No personal pronouns. Start each bullet with a different verb.
- **Projects:** Choose [2-3] that best prove I can do this job. Drop the weakest if space is tight.
- **Skills:** Put the posting's priority skills first within each category. Only list skills that appear in "Confirmed skills" below.
- **Education:** Keep it accurate. Reorder coursework toward the posting if relevant.
- **Header / contact info:** [Phone, email, LinkedIn, portfolio/GitHub. Note anything to always keep or always omit.]

## Action verbs

Start every bullet with a strong past-tense verb (use present tense for a current role). Use a **different verb for each bullet** on the page. Pick from these, grouped by what the bullet is about. Delete any that don't sound like you, and add your own.

- **Creating / building:** Developed, Designed, Implemented, Launched, Shipped, Engineered, Prototyped, Authored, Automated
- **Improving:** Optimized, Refactored, Restructured, Re-engineered, Improved, Reduced, Cut
- **Analyzing / thinking:** Evaluated, Analyzed, Diagnosed, Quantified, Formulated, Assessed, Synthesized, Identified
- **Planning / organizing:** Architected, Mapped, Scoped, Prioritized, Defined, Delivered
- **Teamwork / leadership:** Collaborated, Facilitated, Partnered, Trained, Presented

Avoid starting with "Responsible for", "Helped with", or "Worked on". Avoid repeating the same verb twice on one resume. If a verb is overused (such as "Built"), swap in one from the same group.

## Hard rules

- Do not fabricate jobs, titles, dates, metrics, awards, or skills.
- Do not change my visual template (fonts, margins, section styling).
- Do not turn bullets into paragraphs.
- Prefer tightening over adding. One page beats completeness.
- After editing, check that the resume is exactly one page and fix any overflow before stopping.
- If something in the posting asks for a skill or experience I don't have, **tell me**. Do not stretch the truth to cover it.
- Before finishing, list every change you made so I can check each one.

## Optional: cover letter

If I also want a cover letter, finish the resume first, then write a letter that matches it. Use only the same facts as above.
